# Mohadese AI OS Portfolio

Creative interactive portfolio built with Next.js, React, TypeScript, Tailwind v4, GSAP, Lenis, and Framer Motion.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Edit your data

Edit `src/lib/portfolio-data.ts`.

## Main interactions

- Boot sequence intro
- AI orb hero
- GSAP animations
- Smooth Lenis scrolling
- Command palette with keyboard shortcut `/`
- Interactive dock navigation
- Project lab with case-study preview
- Experience scene switcher
- Magnetic buttons and cursor glow
